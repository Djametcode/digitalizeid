# digitalizeID

Modern digital invitation platform with glassmorphism design. Perfect for weddings, birthdays, and special events.

## Features

- **Glassmorphism Design** - Modern UI with blur effects and transparency
- **Responsive** - Works perfectly on all devices
- **Easy Sharing** - Share via WhatsApp, Instagram, or direct link
- **Background Music** - Add your favorite songs
- **Google Maps Integration** - Help guests find your venue
- **Gift Registry** - Accept digital gifts easily

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** - Lightning fast build tool
- **Framer Motion** - Smooth animations
- **Lucide React** - Beautiful icons
- **CSS3** - Glassmorphism effects with backdrop-filter

## Design Highlights

### Color Palette
- Primary: `#b76e79` (Soft romantic pink)
- Accent: `#c9a96e` (Warm gold)
- Glass effects with blur and transparency

### Typography
- Display: Playfair Display, Cormorant Garamond
- Body: Inter

### Effects
- Animated background orbs
- Floating decorations
- Smooth scroll animations
- Hover transitions with glassmorphism

## Project Structure

```

├── components/

│   ├── Hero.tsx            # Landing section with CTA

│   ├── Templates.tsx       # Template showcase
│   ├── HowItWorks.tsx      # 4-step process
```
